The Cutweave mark: three tracks with staggered cuts, reading as woven. Both files are single-ink SVGs on a 64 × 64 grid.

- `cutweave-mark.svg`: ink `#f2b33d` (the `marigold` token). Use it on dark grounds (`surface-0`, `surface-1`) and in the app icon.
- `cutweave-mark-ink.svg`: ink `#161616` (the light theme's `text-primary`). Use it on light grounds and in print.

Keep clear space of one track height (a quarter of the mark) on every side. The minimum size is 16px. Never recolor it outside these two inks, outline, rotate or add effects. The wordmark "Cutweave" is set in the `display` family at weight 700, with the mark to its left at cap height.

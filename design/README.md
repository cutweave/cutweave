Cutweave is an open-source video editor for creators and the AI agents that work with them. The interface is a precise instrument: it stays neutral so footage looks true, it marks exactly one thing as "here", and it never hides what an agent did. Every surface (the desktop app, plugin panels, the website, docs, Agent Kit output) builds from these tokens and rules.

## Principles

1. **Footage first.** Chrome is true-neutral gray (`surface-0` to `surface-3`, `surface-preview`) and recedes. Color in the UI always means something; it is never decoration.
2. **One thread.** `marigold` marks where you are and what will act: the playhead, the selection, the active tool, the primary button. If two things on screen are marigold, they must be the same idea.
3. **Agents are visible.** Anything generated by AI or proposed by an agent carries `agent` color and a badge. Pending proposals are dashed and hatched until a person accepts them, and history always shows who made each edit.
4. **Dense but calm.** 13px interface text, a 4px grid, small radii, borders before shadows. Pros work for hours in this UI; nothing blinks or bounces during playback.
5. **One name per action.** A button, its menu item, its shortcut tooltip and its MCP tool describe the same command with the same verb (Split, Ripple delete, Generate). Labels match the engine's command names.

## Content fundamentals

**Voice.** Plain, direct and calm, like a skilled editor sitting next to you. Use the editing vocabulary creators already know: clip, track, playhead, keyframe, ripple, render. Address the user as "you". The product never says "I"; the copilot does, in its own panel only.

**Casing and form.** Sentence case everywhere: buttons, menus, titles, tabs. Buttons start with a verb and name the result ("Export video", "Generate clip", "Remove 14 silences"). No exclamation marks, no emoji, no "Oops".

**Numbers.** Timecode is always `HH:MM:SS:FF` in `timecode` or `timecode-lg`. Units follow values with a thin space: `-12.5 dB`, `1920 × 1080`, `23.976 fps`, `5 s`. Costs are estimates with a tilde and the model: "~$0.40 · Kling 3.0 via fal".

**AI and agents.** Say what will happen, what it costs and who does it before it happens. After it happens, say what changed.

| Situation | Write | Not |
|---|---|---|
| Generate button | Generate clip · ~$0.40 | Create magic |
| Agent proposal | Agent proposes 6 changes: remove 14 silences, add captions | AI suggestions available! |
| Over budget | This costs ~$2.10, above your $1.00 agent budget. Approve to continue. | Payment required |
| Missing media | 2 clips are offline. Relink media to keep editing. | Error 404 |
| Export done | Exported 00:00:58 to Shorts_final.mp4 | Success! |
| Destructive | Delete 3 original files from disk? This can't be undone. | Are you sure? |

**Errors** say what happened and the next step, without apology. **Empty states** say what will appear and offer the first action ("Drop video, audio or images here, or press Ctrl+I to import").

## Color

- **Surfaces.** The app frame and gutters use `surface-0`. Panels use `surface-1`. Inputs, cards, menus and dialogs use `surface-2`. Hover uses `surface-3`. The area around the video preview is `surface-preview` and holds nothing but overlays. Timeline lanes alternate `timeline-lane` and `timeline-lane-alt`.
- **Text.** Use `text-primary` for content and values, `text-secondary` for labels, `text-muted` for hints and ruler ticks, and `text-disabled` only for disabled controls. All three readable text colors pass 4.5:1 on `surface-0` to `surface-3` in both themes.
- **Brand.**
  - `marigold` fills primary buttons and draws the `playhead`, with `on-marigold` for text on it.
  - On panels, marigold text and icons use `marigold-text`, which darkens in the light theme.
  - Selected rows and tiles get `marigold-subtle` behind `text-primary`, plus a marigold edge.
- **Agent.**
  - `agent` marks AI-generated media, agent proposals and the copilot. Use `agent-text` for agent wording, and `agent` fill with `on-agent` for the Accept-proposal action.
  - `agent-subtle` fills ghost clips and proposal bars, always with a dashed `agent` outline.
  - Never use agent color for an ordinary primary action.
- **Clip families.** Each clip type has a strong color and a body color.
  - **The pairs:**
    - `clip-media` / `clip-media-body`: video, images, stickers.
    - `clip-audio` / `clip-audio-body`.
    - `clip-graphics` / `clip-graphics-body`: text, compositions, generators.
    - `clip-captions` / `clip-captions-body`.
    - `clip-effects` / `clip-effects-body`: effects, filters, adjustments.
  - **How they're applied:** the strong color draws the 3px header strip, the border and the track icon. The body sits behind thumbnails, waveforms and the `text-primary` label.
  - **Never color alone:** every clip also shows its type icon.
- **Status.** `success`, `warning` and `danger` are text and icon colors on `surface-1` and `surface-2`. They always come with an icon and a word, never color alone. Destructive buttons fill with `danger` and use `on-danger` text.
- **Over video.** Safe areas, grids and transform handles draw in `overlay-guide` with a 1px `overlay-guide-shadow` outline, so they read on any footage.
- **Themes.** Dark is the default and the reference. Light is fully supported through the same tokens, and a high-contrast theme (7:1) will be added as a separate theme. Never write a literal color in a component; if a token is missing, add it here first.

## Typography

- **Families:**
  - **Interface (`ui`):** Instrument Sans, set at its normal width.
  - **Brand moments (`display`):** Bricolage Grotesque.
  - **Timecode and numbers (`mono`):** JetBrains Mono.

  All three are SIL OFL and ship inside the app, so it works offline.
- **Interface scale:**
  - `body` (13/20) is the default.
  - `label` (12/16) for control labels and tabs.
  - `caption` (11/14) for clip labels and tile metadata.
  - `heading` (14/20) for panel titles and inspector sections.
  - `title` (17/24) for dialog titles.
  - `overline` (10/12, uppercase) only for inspector group eyebrows.
- **Numerals:** values in fields and sliders use `numeric`, and times use `timecode` / `timecode-lg`, all with tabular figures so digits don't jump while scrubbing.
- **Display:** `display-xl` and `display-l` appear only on the welcome screen, empty project, template gallery and the website, never inside editing panels.

## Space, size and shape

- **Grid:** a 4px grid via `space-0-5` to `space-12`. Panels pad `space-3`, cards and popovers `space-4`, dialogs `space-6`. Inspector rows are `control-sm` tall with `space-2` between.
- **Controls and targets:**
  - Inspector fields are `control-sm`, buttons `control-md`, dialog primary buttons `control-lg`.
  - The toolbar and transport bar are `toolbar` tall. Panel headers are `panel-header`.
  - Nothing clickable is smaller than `hit-min`; small icons get an invisible hit area.
- **Tracks:** `track-sm` (collapsed), `track-md` (default), `track-lg` (keyframe lanes).
- **Density:** Standard is the values above (`data-density="compact"` on the root). **Comfortable** (`data-density="comfortable"`, Settings > Appearance > Density) is a second set of the same tokens, listed under `density` in `tokens.json`:
  - Controls `control-sm` / `-md` / `-lg` are 28 / 32 / 36 (Standard 24 / 28 / 32) and `hit-min` is 28.
  - `toolbar` is 44 and `panel-header` 36 (Standard 40 and 32).
  - Tracks `track-sm` / `-md` / `-lg` are 36 / 56 / 84 (Standard 32 / 48 / 72). A track with a height of its own keeps it.
  - Padding `space-2` / `-3` / `-4` is 10 / 16 / 20 (Standard 8 / 12 / 16).

  Text, icons, radii and colors are the same in both, so contrast does not change. Components never test the attribute: they read the tokens. The token build refuses a set that makes a token smaller or leaves a control below `hit-min`.
- **Interface scale:** 90 to 150% is the window's zoom, not a token. A canvas sizes its backing store as CSS size × `devicePixelRatio`, so it stays sharp at every scale.
- **Radii:** `radius-sm` for buttons, inputs and clips; `radius-md` for menus and cards; `radius-lg` for dialogs and media tiles; `radius-full` for chips, switches and the playhead flag; `radius-xs` for markers.
- **Depth:** hierarchy comes from surface steps and `border-subtle` / `border-default`. Only floating layers get shadows: `shadow-popover`, `shadow-dialog`, and `shadow-drag` for a clip in flight.

## States

- **Hover:** `surface-3`. Filled buttons use `marigold-hover`, `agent-hover` or `danger-hover` instead.
- **Pressed toggle:** `marigold-subtle` fill with a `marigold-text` icon.
- **Selected:** `marigold-subtle`, plus a 2px `marigold` outline on clips.
- **Focus:** a 2px solid `focus-ring` with 1px offset on every interactive element, including timeline clips. Focus is never removed.
- **Disabled:** `text-disabled`, no hover. Disabled clips and tracks dim to `opacity-disabled`.
- **Borders:** `border-thin` for hairlines and outlines; `border-thick` for selection, focus and the active-tab underline.
- **Proposed (agent):** dashed `agent` outline, `agent-subtle` fill, diagonal hatch.
- **Offline media:** `warning` icon plus the word "Offline" on the clip.

## Motion

- **Timings:** `duration-fast` for hover and toggles, `duration-base` for menus and tabs, `duration-slow` for dialogs, toasts and the proposal reveal. Use `easing-enter` for appearing, `easing-exit` for leaving and `easing-standard` for everything else.
- **During playback, nothing animates** in the timeline or preview except the playhead and the frames themselves.
- **Reduced motion:** under `prefers-reduced-motion`, transitions become instant. Settings > Appearance > Reduce motion overrides the system through `data-motion` on the root: `reduce` makes every transition and animation instant, `full` keeps them when the system asks to reduce, and no attribute follows the system.

## Iconography

- **Base set:** Lucide (ISC license), drawn on a 24-unit grid with a 1.75 stroke. Use `icon-md` in panels and menus, `icon-sm` inside clips and chips, and `icon-lg` in the toolbar and transport. Icons inherit `currentColor`.
- **Custom glyphs:** editor-specific icons (razor, ripple, roll, slip, slide, magnetic track, keyframe diamond, in/out) are drawn on the same grid and stroke.
- **No emoji** in the UI; `sparkles` is reserved for AI and agent actions and always uses `agent-text`.

## Logo

- **Mark:** the Cutweave mark is three tracks with staggered cuts, reading as woven. Use `assets/Logos/cutweave-mark.svg` (marigold ink) on dark grounds and `cutweave-mark-ink.svg` (ink `#161616`) on light grounds.
- **Space and size:** clear space is one track height (a quarter of the mark) on every side. The minimum size is 16px.
- **Wordmark:** "Cutweave" set in `display` at weight 700, mark to the left at cap height.
- **Misuse:** never recolor, outline, rotate or add effects.

## Building with it

- **Tokens:** `tokens.json` is the single source. The repo keeps the canonical copy at `design/tokens.json`. A build step generates CSS custom properties (`--surface-1`, `--radius-sm`, …), the Tailwind v4 `@theme`, TypeScript constants and Rust constants (for engine-drawn overlays and default caption styles).
- **No literal values:** components use `var(--token)` only. A lint rule rejects literal colors outside `design/`.
- **Plugins:** UI plugins receive the same CSS variables, injected into their sandboxed iframe, so third-party panels look native without copying values.
- **Accessibility:** WCAG 2.2 AA everywhere: 4.5:1 for text, 3:1 for borders, icons and the focus ring, `hit-min` targets, full keyboard access. Color never carries meaning alone.

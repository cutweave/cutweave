AssetTile is the media bin card: a 16:9 thumbnail with duration, file name, selection, AI provenance and missing-media states.

**When to use**
- Media, Audio and AI Studio results grids in the asset browser.
- Anywhere an imported or generated asset is dragged onto the timeline.
- Not for timeline clips (use TimelineClip) or list rows (use a `cw-listrow`).

**Anatomy**
`.cw-tile` (`surface-2`, `border-default`, `radius-lg`, `space-1` padding) > `__thumb` (16:9, `surface-3` block, `radius-md`; the real thumbnail or poster replaces the placeholder `__shape`) with `__dur` chip (type: numeric, mono, on `surface-0`) bottom right and optional `__ai` badge top left > `__name` (type: caption, ellipsis). The grid `.cw-tilegrid` uses `space-2` gaps.

**The consumer provides**
Asset id, thumbnail, file name, duration in timecode, provenance (imported vs generated by model), whether the source file is missing, and selection state.

**States**
Default, hover (`surface-3`), selected (`aria-selected="true"`: `marigold-subtle` fill + marigold border), focus-visible, AI-generated (`AI` badge: `agent` fill, `on-agent` text, sparkles), missing (dashed `warning` border, alert icon and the word "Missing" in `warning`).

**Keyboard & accessibility**
`role="listbox"` / `role="option"` with `aria-selected`; arrows move, Shift extends, Space selects, Enter adds to timeline. The AI badge includes the word AI, and missing state uses icon + word. Thumbnails need `alt` or are decorative with the name present.

**Command mapping**
Enter or drag dispatches `timeline.insertAsset {assetId, at:playhead}`; Relink on a missing tile dispatches `media.relink {assetId}`.

**Do**
- Use `agent` only for the AI badge; it denotes generated provenance.
- Keep names in caption type and truncate with ellipsis; full path in the tooltip.
- Show the duration in mono with tabular numerals.

**Don't**
- Don't use `surface-3` as the selected fill; use `marigold-subtle`.
- Don't hide missing tiles; users need to relink.
- Don't overlay anything but the duration and AI badge on the thumbnail.
